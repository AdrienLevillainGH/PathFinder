# PathFinder

Find trail-running segments by terrain (D+, length, grade, descent cap) and
by train access (time from your station, distance from the arrival station).
Built like DayLoad: Vite + React + Tailwind, static on GitHub Pages, no server.

**Preview 0.3 — demo data, real background map.** Terrain filter by D+ or by grade; Komoot-style layout; IGN Plan / aerial / relief / contour lines (or OSM) via MapLibre wherever the page can load map tiles (GitHub Pages, your browser) — the hand-drawn map remains as a fallback inside Claude. Station positions, lines and summits are real
(approximate); train times are a schematic of the TER network; climbs and
their profiles are generated by `pipeline/make_demo_data.py`. The engine,
filters, ranking and screens are the real ones.

```
npm install
npm run data   # regenerate public/data (demo generator)
npm test       # engine checks, brute force as referee
npm run dev
```

## Layout

```
src/PathFinder.jsx   Explore (map + cards), Filters, Saved, How it works, Settings
src/engine.js        access + terrain filters, near misses — no React
src/MapLibreView.jsx explore + segment maps on IGN/OSM tiles (MapLibre)
src/MapView.jsx      hand-drawn fallback map (inside Claude)
src/basemap.js       background maps: IGN Géoplateforme layers, OSM, tile probe
src/Segment.jsx      segment page: map, getting there, elevation, way types, surfaces
src/theme.js         "Trail" theme + DayLoad themes, dl-* classes, grade colours
src/storage.js       local only in the preview; DayLoad's sync code later
src/geo.js           projection, GPX
pipeline/            R pipeline (OSM + IGN RGE ALTI + SNCF/Fluo GTFS + r5r) → public/data; see pipeline/README.md
public/data/         meta, stations, ttm, climbs, access (the data contract)
tests/               engine.test.mjs
```

## Put it online (like DayLoad)

1. Create a public repo `PathFinder` on GitHub.
2. Upload everything in this folder, including `.github/` and `package-lock.json`.
3. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
4. The "Deploy to GitHub Pages" action (copied from DayLoad) builds and publishes:
   https://adrienlevillaingh.github.io/PathFinder/

`vite.config.js` uses `base: "./"`, so the same build works on Pages and inside Claude.
Map sources and their licences: see `src/basemap.js`.
